Сервис для пересылки ответов из **Яндекс.Форм** в личные сообщения или беседы **ВКонтакте** от имени сообщества. Проект имеет веб-интерфейс для управления формами, ботами и маршрутами.

## 🚀 Стек технологий
*   **Бэкенд:** FastAPI (Python 3.11), Gunicorn, SQLAlchemy (Async), PostgreSQL.
*   **Фронтенд:** Flask (Python 3.11), Bootstrap 5, FontAwesome.
*   **Инфраструктура:** Docker, Docker Compose.
*   **Безопасность:** JWT (авторизация), Bcrypt (пароли), Fernet (шифрование токенов ВК в БД).
🌐 Доступ к сервису
Веб-интерфейс: http://<IP_СЕРВЕРА>:8080

Документация API (Swagger): http://<IP_СЕРВЕРА>:8000/docs

🔑 Первый вход
При первом запуске бэкенд автоматически создает администратора:

Email: kiba@test.ru

Пароль: admin

⚠️ Важно: Публичная регистрация закрыта. Новых пользователей может добавлять только администратор через вкладку «Пользователи» в веб-интерфейсе. 
  Для входа через кнопку «Яндекс ID» email пользователя в базе должен совпадать с его Яндекс-почтой.
  
⚙️ Как это работает
Пользователь создает Форму (указывает Survey ID).

Пользователь добавляет ВК Бота (указывает Group ID и Access Token).

Пользователь создает Маршрут: связывает Форму, Бота и peer_id получателя (ID пользователя или 2000000000 + chat_id для бесед).

В настройках Яндекс.Формы пользователь указывает URL вебхука: http://<IP>:8000/webhook/<ID_формы> (ID формы можно посмотреть в таблице).

При отправке формы Яндекс шлет POST-запрос на наш сервер, сервер парсит JSON и отправляет сообщение в ВК.
